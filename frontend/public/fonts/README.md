# Self-hosted fonts

- `Fraunces-Variable.ttf` is the Fraunces variable font from Google Fonts:
  `https://github.com/google/fonts/tree/main/ofl/fraunces`
- `SpaceGrotesk-Variable.ttf` is the Space Grotesk variable font from Google Fonts:
  `https://github.com/google/fonts/tree/main/ofl/spacegrotesk`

Both families are distributed under the SIL Open Font License 1.1. See
`OFL.txt`.
